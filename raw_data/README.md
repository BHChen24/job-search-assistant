# Private Inputs

Put your own input files here. Everything in this directory except this README and the `.gitkeep` files is git-ignored, so nothing you add gets committed.

- `jobs/` — 8 or more related job-posting PDFs for Phase 1.
- `resume/` — exactly one resume PDF for Phase 2.
- `postings/` — optional, for evaluation postings you want to keep out of the Phase 1 set.

Only `.pdf` files are read; other formats are ignored.

Phase 3 takes a PDF path as an argument, so its posting can live in any of these directories.
